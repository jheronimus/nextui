# NextUI for RG35xxSP and RG Arc D

This is a personal fork of [NextUI](https://github.com/LoveRetro/NextUI) designed to run Anbernic RG35xxSPv1 and RG Arc D handhelds. Instead of stock it provides a minimal Alpine image with mainline kernel, Panfrost graphics and all the dependencies. The upside is that you can flash it like a normal firmware and it builds pretty fast. The downside is it's musl-based, so might not be compatible with all software.
